# Chrome Web Store listing

## Name

Shopee Price Tracker

## Summary

Track displayed Shopee Vietnam prices with a local-only dashboard and Chrome-session collection.

## Category

Shopping

## Single purpose

Observe displayed product-price evidence on Shopee Vietnam product pages and send user-requested or
scheduled snapshots to the user's Shopee Price Tracker backend running on the same computer.

## Detailed description

Shopee Price Tracker records the product and variant prices shown to your current Shopee Vietnam
browser session. It works with the open-source Shopee Price Tracker companion backend and dashboard
running locally on your computer.

Before installation: on supported Shopee Vietnam product pages, the extension observes the product
URL, title, image URL, variant identifiers and names, displayed prices, availability, stock when
exposed, and capture time. This information is stored on your computer and sent only to your local
tracker at localhost or 127.0.0.1. It is used only for the price-tracking features described below.
The extension does not collect Shopee cookies, Shopee credentials, request headers, addresses,
payment information, or complete raw API responses.

Main features:

- preview the currently displayed product variant and price;
- track products in a local watchlist;
- collect exact prices for available variants using your current Chrome session;
- process manual and scheduled price-check jobs in inactive tabs;
- inspect upload and price-check queue status; and
- open the local dashboard for variant history and price-drop settings.

Automatic snapshot submission and scheduled background collection are disabled by default. The
extension contains no advertising and sends no tracking data to a developer-operated server.

The companion Node.js application must be installed and running locally for watchlist, history,
and scheduled-job features. Setup instructions and source code are available from the project
website.

Shopee Price Tracker is an independent project and is not affiliated with, endorsed by, or sponsored
by Shopee.
