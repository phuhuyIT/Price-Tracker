# Store asset checklist

Store screenshots must show the actual current extension and companion dashboard. Do not use
AI-generated or obsolete mock UI.

## Current screenshots

- `popup-product-capture.png` - 1280 x 800, supported Shopee product page with the extension popup,
  exact selected-variant price, and stock.
- `history-variant-chart.png` - 1280 x 800, local dashboard history with dated variant series.
- `dashboard-watchlist.png` - 1280 x 800, connected local dashboard with search and filters,
  tracked product cards, current prices, availability, and product actions.

All images use actual v1.1.0 UI and contain no visible account, token, chat, or browser-profile
information. The history image is suitable as a secondary screenshot; its large catalogue makes the
legend intentionally dense.

An Options screenshot may be added to show the loopback-only backend and opt-in background
collection controls.

## Capture safety

- Use a clean Chrome profile and a public disposable product.
- Hide bookmarks, profile names, email addresses, notifications, unrelated tabs, and operating
  system paths.
- Use only sanitised local database records.
- Do not show Telegram credentials, chat IDs, application sessions, extension debug output, cookies,
  request headers, or Chrome developer-account information.
- Confirm each screenshot matches the exact submitted version.

Promotional images are optional. If created later, use consistent project branding and do not imply
affiliation with or endorsement by Shopee.
