# Phase 13 documentation and release preparation

## Status

Phase 13 is complete as of 2026-08-13. The release documentation, synchronized
versions, local artifact exporter, schema backup, privacy/configuration checks,
and complete regression gate all pass. The final verified release commit is the
target of the annotated local `v1.0.0` tag.

## Release decisions

- The first complete MVP release is `v1.0.0`.
- The backend remains loopback/local-only with one local SQLite database.
- Production collection uses the unpacked `apps/extension` build in the user's
  current signed-in Chrome profile.
- Playwright and `chrome-extension` remain discovery/regression tooling and are
  not production scheduled collectors.
- Generated release artifacts remain ignored under `dist`; the annotated Git
  tag is the versioned source release.
- Public hosting, Chrome Web Store publication, and multi-device sync remain
  Phase 14 or later work.

## Release configuration

The application, server workspace, shared workspace, package lock, and MVP
extension manifest are synchronized at `1.0.0`. The retained legacy extension
keeps its independent `1.2.0` version.

`.env.example` now groups and explains all validated settings. The production
configuration test proves the accepted v1.0.0 deployment boundary:
`NODE_ENV=production`, loopback host, optional extension origin, local database,
and authentication disabled.

`.gitignore` now covers databases and their SQLite sidecars regardless of
directory, in addition to environment files, logs, generated builds, and Chrome
profiles. The repository privacy test validates those rules.

No unconditional production debug statement was found. The extension's sole
`console.debug` is deliberately gated by the off-by-default sanitised debug
setting and logs only the allowlisted capture summary. Test password strings are
synthetic fixtures. Automated repository scanning found no Telegram Bot API
token, and real credentials remain only in ignored local environment state.

## Release exporter

`npm.cmd run release:prepare` builds the extension and creates:

```text
dist/releases/shopee-price-tracker-v1.0.0
```

The 28-file artifact contains:

- the complete 15-file unpacked Manifest V3 extension;
- `.env.example` and release/setup/developer/troubleshooting documentation;
- a manifest declaring release `1.0.0` and database schema version 4;
- all four checksummed source migrations;
- an empty `schema-v4.sql` generated by applying the migrations in memory and
  verified by restoring it into a second empty database; and
- SHA-256 checksums for every packaged input file.

The exporter resolves `better-sqlite3` from the server workspace, refuses
mismatched release versions, verifies the built extension version, and limits
regeneration deletion to its exact versioned directory under the chosen release
base.
